# Glass Keyboard

Fork of [Hacker's Keyboard](https://github.com/klausw/hackerskeyboard) 1.40.7 (Apache 2.0).

## What's new
- **Keyboard opacity** slider (20-100%) so you can see the app behind the keyboard.
- **Overlay on top of app** option: the keyboard floats over the app without resizing it (useful for games like Cataclysm DDA).

## Download
[Latest APK](https://github.com/tarasveresuk1-hue/glass-keyboard/releases/tag/latest)

Install, then enable it in Settings > System > Keyboard > On-screen keyboard. Settings are under "Keyboard view settings".

## Notes
- Debug-signed build; installs alongside the original Hacker's Keyboard.
- Tested on Android 16 (OnePlus). Overlay behavior may vary on other devices.
