# Glass Keyboard

Transparent on-screen keyboard for Android, built for playing **Cataclysm: DDA on a phone**. Fork of [Hacker's Keyboard](https://github.com/klausw/hackerskeyboard) 1.40.7 (Apache 2.0): full PC-style layout with Ctrl, Alt, Esc, Tab and arrow keys.

## Why for CDDA
- The keyboard floats over the game, so the game does not shrink or leave a black strip under the keys.
- Adjustable transparency lets you see the map through the keyboard.
- All keys CDDA needs are on the keyboard: Esc, Tab, Ctrl, Alt, F-keys, arrows.

## Download
[GlassKeyboard.apk (latest)](https://github.com/tarasveresuk1-hue/glass-keyboard/releases/download/latest/GlassKeyboard.apk)

## Setup for CDDA
1. Install the APK and enable it: Settings > System > Keyboard > On-screen keyboard.
2. Open the keyboard settings and turn on "Overlay on top of app".
3. Set opacity to about 40-60%.
4. In CDDA: Options > Graphics, set Software rendering to No.

## Notes
- Debug-signed build, installs alongside the original Hacker's Keyboard.
- Tested on OnePlus Nord, Android 16. Overlay behavior may differ on other devices.
